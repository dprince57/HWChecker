# HWChecker
A quick hw checker I created to check assignments before turning in. It checks for any discrepancies in your output compared to thiers.

Usage: [program name] [Professors program] [Your Program] [Any files needing piped in]
For example: ./checker ./prof/info ./info file1.txt file2.txt
